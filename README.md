# Ricola Hero Landing Page Clone

A clean, modern recreation of the Ricola desktop landing page hero section, built with semantic HTML5 and modern CSS3 (Grid & Flexbox).

## Features

- **Floating Pill Navigation:** Centered navigation bar using CSS Grid (`1fr auto 1fr`) to ensure perfect alignment between left links, center branding, and right utility icons.
- **Fluid Typography:** Uses CSS `clamp()` for responsive headline scaling across all screen widths without sudden breakpoint jumps.
- **Hero Stacking:** Full-bleed background with CSS linear gradient overlays for enhanced text contrast and legibility.
- **Semantic HTML5:** Built with accessible tags (`<header>`, `<nav>`, `<main>`) and inline SVG icons.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Custom Properties / CSS Variables)
- **Google Fonts** (Plus Jakarta Sans & Inter)
